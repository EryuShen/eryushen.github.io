Momentum Internship Program

A 24-week curriculum that takes interns from onboarding to client work, one milestone at a time

Used for two intern cohorts, now the standard for every new cohort

PROJXON's remote interns needed to get productive quickly, build skills in a deliberate order and be ready for client-facing work by the end. I audited the previous internship model using intern feedback and program data, then redesigned it as a milestone-based program in Canvas.

Six phases, each with more ownership

Interns move from guided warm-ups to team projects, then their own portfolio project, then real client work. Each phase hands over a little more responsibility than the last.

  1. Weeks 1–3OnboardingOrientation and foundationsTool setup, intro modules, team building, warm-up tasks
  2. Weeks 4–6Warm-up projectsSkill application and feedbackMini projects, planning tools, peer collaboration
  3. Weeks 7–13Team projects 1 and 2Project-based learningA full group project, real-time iteration, delivery in ClickUp
  4. Weeks 14–17Portfolio projectIndividual ownership and storytellingDesign and deliver a signature case study
  5. Weeks 18–21Contract clientReal-world readinessSolve a live or simulated client brief as a team
  6. Weeks 22–24OffboardingReflection and career launchRetrospective, handoff docs, final feedback, alumni transition

Every week works the same way

Twenty-four weeks is a long time to stay oriented. Every module uses the same four-part template, so interns always know where to look, and coaches always know where an intern stands.

  1. Module overviewThe week's goals and what to deliver.
  2. Learning materialsShort, targeted lessons from PROJXON's course library, picked for what the week needs.
  3. A human touchpointEvery week includes one, rotating so interns get each kind regularly.Check-inCoachingPerformance review
  4. Weekly checklistWhat "done" looks like before moving on.

Projects tracked by milestone, not by deadline alone

25%50%75%100%

Each multi-week project has a weekly checkpoint, such as 25%, 50%, 75% and final delivery, so problems show up while there's still time to coach.

Design decisions

  • Structure around milestonesWeekly progress checkpoints on every project turn a long program into short, visible steps, for interns and their coaches.
  • Hand over responsibility graduallyWarm-ups build confidence before team projects; team projects build skills before interns own a portfolio project and then client work.
  • Reuse the course library, sequencedInstead of writing new content, I worked with subject matter experts to pull the right lessons from existing courses, like ClickUp, communication tools and career development, into the week interns need them.
  • Build reflection and coaching into the scheduleCheck-ins, coaching and performance reviews are part of the weekly template, not left to chance, adding up to 8+ reflection check-ins and 5+ coaching sessions per intern.

Outcome

Two cohortsImplemented for the 2025 Q2 and Q3 intern cohorts.
The new standardAdopted as the onboarding structure for every future cohort.
100 learnersReached through virtual training I delivered.

With clear weekly milestones, reflection points and coaching check-ins, onboarding became clearer, interns stayed more engaged, and projects lined up better across departments.

This project changed how I think about learning design: not only creating content, but designing momentum, motivation and meaning.
